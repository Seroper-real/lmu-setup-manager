Edge cases
- all ON: checkboxes shown checked+disabled, search/buttons disabled; counter shows M / M
- ON->OFF with empty selected: selected = all car names, saved
- "Deseleziona tutte" gives empty selected with all=false (backend filters everything out)
- Cars with null carClass grouped last under "Other"; class order hypercar, lmp2, lmp3, lmgt3, lmgte (case-insensitive)
- Select/deselect all act on all cars, not only search-visible ones
